# Nexo for Windows

Nexo is a customizable launcher for Windows. Press **Alt+Space** to find apps and files or open everyday tools.

- App and file search, custom commands and keyboard shortcuts.
- Clipboard history with pinned items and an encrypted password vault.
- Image editing, video trimming and media conversion.
- File sharing, translation and calculations.
- Custom themes and an interface in English and Italian.
- Automatic update checks and optional startup with Windows.
